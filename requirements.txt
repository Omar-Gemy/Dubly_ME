# Dubly ME — dependency index  (NOT directly installable)
# ═════════════════════════════════════════════════════════════════
# This file used to list EVERY dependency across all three virtualenvs in one
# flat set. Installing it into a single environment reproduced exactly the
# resolver conflicts the 3-venv design exists to avoid (torch 2.1.2 for the
# pinned ASR stack vs. whatever CUDA build the LLM/TTS stacks need). It is now
# an index only — deliberately empty of requirements (audit: flat-requirements
# warning in architecture_data_flow_map.md §7).
#
# Install the venv you actually need:
#
#   requirements/asr.txt      Venv 1 — Phases A, B, C   (torch 2.1.2, whisperx)
#   requirements/llm.txt      Venv 2 — Phase D          (transformers 4.47.1, autoawq)
#   requirements/audio.txt    Venv 3 — Phases E, F1–F3  (Coqui TTS, scipy, pyrubberband)
#   requirements/demucs.txt   Venv 4 — Phase F0         (demucs)
#
#   requirements-colab.txt    Colab base kernel only (ASR + LLM co-installed);
#                             the TTS and Demucs venvs are built separately by
#                             the notebook's setup cells.
#
# System dependencies (never pip): FFmpeg, and rubberband-cli for Phase F1's
# preferred time-stretch engine.
#
# Orchestration: src/run_pipeline.py resolves one interpreter per venv via
#   --python-asr / --python-llm / --python-audio / --python-demucs
# or the matching DUBLY_PY_* environment variables.
